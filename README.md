# AI Audit Telegram Bot

Коммерческий Telegram-бот для рекламного агентства:
START → AI-аудит → квалификация → предварительный результат → заявка эксперту.

## Возможности
- `/start` и главное меню
- сбор ниши, бюджета, источников клиентов, заявок и сайта
- предварительная диагностика по правилам
- уведомление администратора о новой заявке
- SQLite для хранения лидов
- готовая точка расширения под OpenAI Responses API
- конфигурация через `.env`
- Dockerfile для запуска на сервере

## Запуск

1. Создайте бота через @BotFather и получите токен.
2. Скопируйте `.env.example` в `.env`.
3. Заполните:
   - `BOT_TOKEN`
   - `ADMIN_CHAT_ID`
   - `OPENAI_API_KEY` (необязательно на первом этапе)
4. Установите Python 3.11+.
5. `pip install -r requirements.txt`
6. `python main.py`

Для продакшена лучше использовать webhook + HTTPS или контейнер на VPS.
